# ServiceWatchdog

Windows-приложение для мониторинга служб и процессов: раз в заданный интервал проверяет,
запущена ли служба/процесс, и если нет — запускает.

## Возможности

- Список правил: можно добавить сколько угодно проверок.
- Каждое правило — либо **служба Windows** (по имени службы, с выбором из списка установленных),
  либо **процесс/приложение** (путь к .exe + опциональные аргументы командной строки).
- У каждого правила свой интервал проверки в секундах.
- Приложение сворачивается в трей (значок в области уведомлений), при закрытии окна крестиком —
  продолжает работать в фоне. Выход — через пункт меню трея "Выход".
- Опция "Запускать при входе в Windows" — создаёт ярлык в папке автозагрузки пользователя.
- Настройки (список правил) хранятся в `%AppData%\ServiceWatchdog\settings.json`.
- Требует прав администратора (нужно для запуска большинства служб через `ServiceController.Start()`).

## Сборка

Требуется .NET 8 SDK.

```
cd ServiceWatchdog
dotnet build -c Release
```

Готовый exe: `ServiceWatchdog\bin\Release\net8.0-windows\ServiceWatchdog.exe`.
Требует установленный на целевой машине .NET 8 Desktop Runtime.

### Публикация одним файлом (без установки .NET на целевой машине)

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Результат — ровно один exe (~70 МБ, включает весь .NET runtime, сжат) в
`ServiceWatchdog\bin\Release\net8.0-windows\win-x64\publish\ServiceWatchdog.exe`.
Его можно скопировать на любой Windows 10/11 x64 ПК и запустить без предустановленного .NET.

## Использование

1. Запустите `ServiceWatchdog.exe` (подтвердите запрос UAC — нужны права администратора).
2. Нажмите "Добавить", выберите тип (служба/процесс), укажите имя службы (можно выбрать из списка
   кнопкой "Выбрать…") или путь к .exe и аргументы запуска, задайте интервал проверки.
3. При необходимости включите "Запускать при входе в Windows".
4. Приложение будет проверять правила в фоне; статус и журнал событий видны в главном окне.
